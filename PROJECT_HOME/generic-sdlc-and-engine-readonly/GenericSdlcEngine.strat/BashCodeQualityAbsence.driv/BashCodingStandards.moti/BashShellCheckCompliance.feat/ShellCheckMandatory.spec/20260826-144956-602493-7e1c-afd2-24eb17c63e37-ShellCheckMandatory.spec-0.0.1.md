# ShellCheckMandatory: ShellCheck Must Pass Clean On All Scripts

## Specification Statement

Running `shellcheck` on every `.sh` file in the project MUST produce exit
code 0 (no errors, no warnings). This applies to all `.sh` files in
`src/main/`, `src/test/`, and `boot/` directories.

ShellCheck is a static analysis tool that detects common bash pitfalls,
quoting errors, uninitialized variables, and portability issues.

## Rationale

ShellCheck catches classes of bugs that are invisible to manual review:
word splitting, glob expansion, unquoted variables, and POSIX compatibility
issues.

## Constraints

| Constraint | Value | Condition |
|------------|-------|-----------|
| shellcheck exit 0 | On every .sh file | Always |
| No errors (SC####) | Zero error-level findings | Always |
| No warnings (SC####) | Zero warning-level findings | Unless suppressed |

## Leaf Value

> 🛑 **Primitive** — terminal specification.

**Value:** `shellcheck` exit code 0 on all `.sh` files

## Measurement Method

```bash
# Run ShellCheck on all scripts
find . -name '*.sh' -type f | while read f; do
shellcheck "$f" || { echo "FAIL: $f"; exit 1; }
done
echo 'PASS: all scripts clean'
```
