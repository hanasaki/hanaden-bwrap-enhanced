# FunctionNaming: Bash functions MUST use snake_case. Exported variables

## Specification Statement

All bash functions MUST be named in snake_case (e.g., `validate_input`,
`run_sandbox`). All exported environment variables MUST use UPPER_CASE
(e.g., `PROJECT_HOME`, `BWRAP_SH`). Local variables SHOULD use lower_case
or snake_case.

## Rationale

Consistent naming conventions make code readable and distinguish between
local variables, exported variables, and functions at a glance.

## Constraints

| Constraint | Value | Condition |
|------------|-------|-----------|
| Functions use snake_case | No camelCase or PascalCase | Always |
| Exports use UPPER_CASE | No lowercase exports | Always |

## Leaf Value

> 🛑 **Primitive** — terminal specification.

**Value:** `snake_case functions, UPPER_CASE exports`

## Measurement Method

```bash
# Check function naming
grep -oP '(?<=^function )[a-zA-Z_]+|^[a-zA-Z_]+\(\)' "$SCRIPT" | \
grep -v '^[a-z_]*$' && echo 'FAIL: non-snake_case function found' || echo 'PASS'
```
