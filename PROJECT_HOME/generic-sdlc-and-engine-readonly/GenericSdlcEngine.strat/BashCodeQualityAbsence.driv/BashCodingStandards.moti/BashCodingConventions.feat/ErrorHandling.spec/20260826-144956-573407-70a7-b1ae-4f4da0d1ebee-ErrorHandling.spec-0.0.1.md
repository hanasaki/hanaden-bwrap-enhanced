# ErrorHandling: Every bash script MUST include set -euo pipefail

## Specification Statement

Every `.sh` file MUST include `set -euo pipefail` as the second executable
line (after shebang, before any other code). This enables:
- `-e`: exit on first error
- `-u`: treat unset variables as errors
- `-o pipefail`: pipe failure propagation

This combination ensures that no error goes unhandled and no undefined
variable is silently expanded to empty string.

## Rationale

Without strict error handling, bash scripts silently continue after failures,
producing incorrect results or corrupting state without any error signal.

## Constraints

| Constraint | Value | Condition |
|------------|-------|-----------|
| set -euo pipefail present | After shebang | Every .sh file |
| Placed before any logic | Lines 1-3 of file | Always |
