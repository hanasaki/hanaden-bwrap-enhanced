# BashCodingStandards: Bash Coding Conventions With ShellCheck Compliance

## Proposed Solution

Establish two pillars of bash code quality:

1. **Coding conventions.** Every script MUST use `#!/usr/bin/env bash` as
its shebang, `set -euo pipefail` for error handling, snake_case for
functions, and UPPER_CASE for exported variables.

2. **ShellCheck compliance.** Every `.sh` file MUST pass ShellCheck clean.
Suppressions are allowed only with inline comments providing justification.
Unjustified suppressions are violations.

## Business / Technical Impact

| Impact dimension | Current state | Target state | Delta |
|------------------|---------------|--------------|-------|
| Code style | Inconsistent | Conventions defined | Uniform style |
| Error handling | Optional | Mandatory set -euo pipefail | Fail-fast |
| Static analysis | None | ShellCheck mandatory | Automated quality gate |
