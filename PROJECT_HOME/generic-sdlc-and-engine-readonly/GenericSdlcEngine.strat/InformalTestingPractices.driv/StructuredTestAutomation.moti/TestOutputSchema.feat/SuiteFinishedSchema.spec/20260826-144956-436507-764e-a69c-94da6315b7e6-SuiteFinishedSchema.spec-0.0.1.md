# SuiteFinishedSchema: The suite_finished record MUST contain finished_at, total,

## Specification Statement

When a test suite completes, it MUST emit a single `suite_finished` JSONL
record containing:
- `type`: `"suite_finished"`
- `finished_at`: ISO 8601 UTC timestamp
- `total`: total test count
- `passed`: count of PASS results
- `failed`: count of FAIL results
- `skipped`: count of SKIP results
- `overall_status`: `"PASS"` if failed = 0, else `"FAIL"`

## Rationale

The suite_finished record enables automated CI gating: if overall_status
is FAIL, the pipeline stops.

## Constraints

| Constraint | Value | Condition |
|------------|-------|-----------|
| type = suite_finished | Exact string | Always |
| total = passed + failed + skipped | Arithmetic check | Always |
| overall_status = PASS iff failed = 0 | Logic check | Always |

**Value:** `{"type":"suite_finished","total":N,"passed":N,"failed":N}`
