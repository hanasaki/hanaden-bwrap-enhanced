# SuiteStartedSchema: The suite_started record MUST contain suite_id, suite_name,

## Specification Statement

When a test suite begins execution, it MUST emit a single `suite_started`
JSONL record containing:
- `type`: `"suite_started"`
- `suite_id`: the spec filename-id + `-SUITE`
- `suite_name`: human-readable suite name
- `started_at`: ISO 8601 UTC timestamp
- `spec_file`: relative path to the spec this suite validates

## Rationale

The suite_started record establishes the context for all subsequent test_case
records, enabling log correlation and timing analysis.

## Constraints

| Constraint | Value | Condition |
|------------|-------|-----------|
| type = suite_started | Exact string | Always |
| suite_id present | Non-empty string | Always |
| started_at is ISO 8601 | Timestamp format | Always |

## Leaf Value

> 🛑 **Primitive** — terminal specification.

**Value:** `{"type":"suite_started","suite_id":...,"started_at":...}`
