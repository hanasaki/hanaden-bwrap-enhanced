# ImplStateDerivation: Test Implementation State is Derived, Not Stored

## Specification Statement

The implementation state of a test case MUST be derived dynamically at
read-time by inspecting the test file at the path declared in `tdd.test-file`.
It MUST NOT be stored as a static value in any spec document frontmatter,
test table column, or markdown field.

Pass/fail execution status MUST come exclusively from
`target/test.run.report/latest.jsonl` — never from the spec document.

## Rationale

Storing implementation state statically in spec docs creates a **completion
theater** vulnerability: an AI agent or developer can mark a test `GREEN` or
`COMPLETE` without writing real test code. The anti-reward-hacking mandate
requires that claims of completion derive from verifiable physical artifacts
(the test file on disk), not from editable metadata fields.

The three derivation states map to real filesystem conditions:

| State | Symbol | Derived From |
|:---|:---|:---|
| `NOT_STARTED` | `○` | `tdd.test-file` path does not exist on disk |
| `STUBBED` | `◑` | File exists; all `@test` bodies are stubs (zero real assertions) |
| `COMPLETE` | `●` | File exists; ≥1 `@test` body contains a real assertion |

## Constraints

| Constraint | Value | Condition |
|:---|:---|:---|
| impl_state is derived, never authored | No spec field stores this value | Always |
| NOT_STARTED when file absent | `! [ -f "$tdd_test_file" ]` | Always |
| STUBBED when file has only stubs | All `@test` bodies match stub pattern | File exists |
| COMPLETE when file has real assertions | ≥1 `assert*` or `[ $status` line present | File exists |
| pass/fail never in spec doc | JSONL-only | Always |

## Measurement Method

```bash
#!/usr/bin/env bash
# Derive impl_state for a given spec's tdd.test-file
derive_impl_state() {
  local test_file="$1"

  if [[ ! -f "$test_file" ]]; then
    echo "NOT_STARTED"
    return
  fi

  # Extract @test body lines — filter out blank, comment, skip, echo, todo lines
  local real_assertions
  real_assertions=$(grep -E '^\s*(assert_|assert |run |status|output|lines|\[\s*\$)' "$test_file" \
    | grep -vE '^\s*#|^\s*skip|^\s*echo|^\s*:' \
    | wc -l)

  if [[ "$real_assertions" -gt 0 ]]; then
    echo "COMPLETE"
  else
    echo "STUBBED"
  fi
}
```
