# NoHostSideEffects: Tests MUST NOT produce untracked host side effects

## Specification Statement

Test execution MUST NOT leave traces on the host system. All temporary files
MUST be created in a per-test tmpdir that is cleaned up in teardown. Environment
variables MUST NOT be mutated globally. No network calls unless explicitly
required by the test and documented.

## Rationale

Untracked side effects create flaky tests, interfere with parallel execution,
and may corrupt the development environment.

## Constraints

| Constraint | Value | Condition |
|------------|-------|-----------|
| Tempfiles in per-test tmpdir | Cleaned in teardown | Always |
| No global env mutation | Subshell isolation | Always |
| No untracked network calls | Documented if needed | Always |

> 🛑 **Primitive** — terminal specification.
