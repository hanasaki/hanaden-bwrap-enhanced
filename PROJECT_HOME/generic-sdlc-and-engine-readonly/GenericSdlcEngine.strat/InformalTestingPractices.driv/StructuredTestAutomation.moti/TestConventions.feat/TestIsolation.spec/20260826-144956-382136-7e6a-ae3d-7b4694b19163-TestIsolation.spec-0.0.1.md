# TestIsolation: Each test MUST run in isolation with no shared state

## Specification Statement

Each test case MUST execute with a clean initial state. No test may depend on
the side effects of a previous test. Shared fixtures MUST be re-initialized
before each test. Global variables MUST NOT carry state between tests.

## Rationale

Shared state between tests creates order-dependent failures that are
difficult to reproduce and diagnose.

## Constraints

| Constraint | Value | Condition |
|------------|-------|-----------|
| No shared mutable state | Clean state per test | Always |
| Fixtures re-initialized per test | setup() runs before each | Always |

## Leaf Value

> 🛑 **Primitive** — terminal specification.

**Value:** `zero shared state between tests`
