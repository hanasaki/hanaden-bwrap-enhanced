# ParentField: Parent Field References Hierarchical Parent Filename-ID

## Specification Statement

Every non-root SDLC artifact MUST contain a `parent:` field in its YAML
frontmatter. The value MUST be the `filename-id` of the parent node:

- DRIV.parent → STRAT filename-id (the strategy this problem serves)
- MOTI.parent → DRIV filename-id (the problem this solution addresses)
- FEAT.parent → MOTI filename-id or parent FEAT filename-id
- SPEC.parent → FEAT filename-id or parent SPEC filename-id

The parent filename-id MUST resolve to an existing file in the tree. Dangling
parent references are a tree integrity violation.

## Rationale

Without a parent field, there is no machine-readable way to reconstruct
the SDLC hierarchy. The children-discover-parent pattern (where each child
stores its parent's filename-id, and no node stores a children list) ensures
that adding or removing a child never requires editing the parent file.

## Constraints

| Constraint | Value | Condition |
|------------|-------|-----------|
| DRIV parent → STRAT | parent contains STRAT filename-id | Always |
| MOTI parent → DRIV | parent contains DRIV filename-id | Always |
| FEAT parent → MOTI or FEAT | parent contains MOTI or FEAT filename-id | Always |
| SPEC parent → FEAT or SPEC | parent contains FEAT or SPEC filename-id | Always |
| STRAT has no parent | parent field absent or omitted | Always |
| Dangling parent → integrity violation | parent filename-id must resolve | Always |

## Measurement Method

```bash
# Validate parent: field resolves
FILE="$1"
PARENT=$(grep '^parent:' "$FILE" | sed 's/^parent:[[:space:]]*//')
if [[ -z "$PARENT" || "$PARENT" == "null" ]]; then
echo "INFO: no parent (root node)"
exit 0
fi
# Search tree for file matching parent filename-id
FOUND=$(find "$TREE_ROOT" -name "${PARENT}.md" -type f 2>/dev/null)
if [[ -n "$FOUND" ]]; then
echo "PASS: parent resolves to $FOUND"
else
echo "FAIL: dangling parent reference: $PARENT"
exit 1
fi
```
