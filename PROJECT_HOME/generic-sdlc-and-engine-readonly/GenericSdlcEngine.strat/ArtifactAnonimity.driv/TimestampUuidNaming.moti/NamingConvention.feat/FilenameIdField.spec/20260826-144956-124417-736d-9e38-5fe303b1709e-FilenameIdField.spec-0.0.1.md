# FilenameIdField: Filename-ID Frontmatter Must Match Filename Stem

## Specification Statement

Every SDLC artifact file MUST contain a `filename-id` field in its YAML
frontmatter. The value of `filename-id` MUST be an exact string match with
the filename after removing the `.md` extension. No `.class`, `.md`, or any
other suffix is included in `filename-id` — it stores the **stem only**.

Example:
- Filename: `20260826-143048-123456-7abc-9def-1234567890ab-MyNode.spec-0.0.1.md`
- filename-id: `20260826-143048-123456-7abc-9def-1234567890ab-MyNode.spec-0.0.1`

## Rationale

The filename-id is the single identity for every document. It appears in
`parent:`, `references:`, and `supersedes:` fields of other documents. If the
filename-id doesn't match the filename stem, cross-reference resolution fails
silently — a tool looking for a file by its filename-id would not find it.

## Constraints

| Constraint | Value | Condition |
|------------|-------|-----------|
| filename-id = filename minus .md | Exact string match | Always |
| No class suffix in filename-id | Already part of stem | Always |
| No .md extension in filename-id | Stem only | Always |

## Leaf Value

> 🛑 **Primitive** — terminal specification.

**Value:** `filename_stem == filename-id` (boolean equality)
**Source:** All Hanaden templates — `filename-id` is the single identity

## Measurement Method

```bash
# Extract stem and compare to frontmatter
FILE="$1"
STEM=$(basename "$FILE" .md)
FID=$(grep '^filename-id:' "$FILE" | sed 's/^filename-id:[[:space:]]*//')
if [[ "$STEM" == "$FID" ]]; then
echo "PASS: filename-id matches stem"
else
echo "FAIL: stem='$STEM' but filename-id='$FID'"
exit 1
fi
```
