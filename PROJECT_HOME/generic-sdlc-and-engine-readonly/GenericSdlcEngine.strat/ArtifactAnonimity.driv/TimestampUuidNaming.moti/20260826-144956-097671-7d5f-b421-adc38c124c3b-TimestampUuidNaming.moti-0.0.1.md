# TimestampUuidNaming: Timestamp Plus UUIDv7 Embedded Filename Identity

## Proposed Solution

Every SDLC artifact filename embeds a Hanaden UUIDv7 Extended prefix:
`YYYYMMDD-HHMMSS-uuuuuu-7xxx-Nxxx-xxxxxxxxxxxx-Slug.class-version.md`.

This provides three properties that resolve the ArtifactAnonimity driver:

1. **Temporal ordering.** The YYYYMMDD-HHMMSS-uuuuuu prefix encodes creation
time to microsecond precision in UTC, enabling chronological sorting by
filename alone.

2. **Global uniqueness.** The CSPRNG segments (version nibble 7 + variant +
random) provide 72 bits of entropy, making collisions astronomically unlikely
even without coordination between concurrent creators.

3. **Machine-independent identity.** No registry, counter service, or shared
database is needed. Any machine with a clock and CSPRNG can generate a
valid, unique filename.

**Alternatives considered and rejected:**
- Sequential counters: require coordination (shared counter state)
- Content-hash names: unstable on any edit (hash changes with content)
- Registry-assigned IDs: require central authority (single point of failure)

## Business / Technical Impact

| Impact dimension | Current state | Target state | Delta |
|------------------|---------------|--------------|-------|
| Naming uniqueness | Collision-prone slugs | Cryptographic uniqueness | 72 bits of CSPRNG entropy |
| Temporal ordering | Unordered filenames | Chronological by name | Microsecond-precision sort |
| Coordination overhead | Manual coordination | Zero coordination | No shared state required |
