# TestFilePath: TDD Test-File Field Contains Relative Test Path

## Specification Statement

The `tdd.test-file` field in YAML frontmatter MUST contain a relative path
(from PROJECT_HOME) to the test script that validates this specification.
The path MUST start with `src/test/` and mirror the SDLC hierarchy.

When `tdd.state` is `NOT_STARTED`, `tdd.test-file` MAY be `null` (test not
yet written). Once the test is written, the field MUST be updated to the
actual path.

## Rationale

A machine-readable path enables automated tools to run the exact test that
validates a spec without searching the filesystem.

## Constraints

| Constraint | Value | Condition |
|------------|-------|-----------|
| tdd.test-file starts with src/test/ | Relative path | When non-null |
| tdd.test-file path exists on disk | File must exist | When tdd.state ≠ NOT_STARTED |
| tdd.test-file null allowed | When tdd.state = NOT_STARTED | Only NOT_STARTED |

## Leaf Value

> 🛑 **Primitive** — terminal specification.

**Value:** Relative path to test script
**Source:** SpecificationTmpl.tmpl — tdd block

## Measurement Method

```bash
# Validate tdd.test-file resolves
TEST_FILE=$(grep 'test-file:' "$SPEC_FILE" | sed 's/.*test-file:[[:space:]]*//')
if [[ "$TEST_FILE" == "null" ]]; then
echo 'INFO: test not yet written'
else
[[ -f "$PROJECT_HOME/$TEST_FILE" ]] && echo 'PASS' || echo 'FAIL: test file missing'
fi
```
