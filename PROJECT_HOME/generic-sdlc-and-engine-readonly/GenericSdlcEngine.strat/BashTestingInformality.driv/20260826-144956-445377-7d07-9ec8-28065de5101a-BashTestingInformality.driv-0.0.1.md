# BashTestingInformality: Bash Test Execution Is Unstructured

## Problem Statement

Bash tests in the project lack standardization at every level:

1. **No standard runner.** Some tests use raw bash assertions, some use ad-hoc
helper functions, some use bats. There is no single mandated test framework.

2. **No discovery convention.** Test files are named inconsistently — some use
`test_*.sh`, some use `*_test.sh`, some have no naming convention.

3. **No structured output.** Test output is free-form text. There is no TAP,
JSONL, or other machine-parseable format, making automated result
aggregation impossible.

## Business / Technical Impact

| Impact dimension | Current state | Target state | Delta |
|------------------|---------------|--------------|-------|
| Test runner | Inconsistent | bats-core mandated | Single framework |
| File naming | Ad-hoc | test_*.sh convention | Discoverable |
| Output format | Free-form text | TAP → JSONL pipeline | Machine-parseable |
