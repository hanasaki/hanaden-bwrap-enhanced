# BatsHelperLibs: bats-support, bats-assert, and bats-file MUST be

## Specification Statement

The three standard bats helper libraries — bats-support, bats-assert, and
bats-file — MUST be installed in the `test_helper/` directory within the
test tree. Test files load them via:
```bash
load "test_helper/bats-support/load"
load "test_helper/bats-assert/load"
load "test_helper/bats-file/load"
```

## Rationale

The helper libraries provide assert_success, assert_failure, assert_output,
and file assertion functions that make tests readable and maintainable.

## Constraints

| Constraint | Value | Condition |
|------------|-------|-----------|
| bats-support in test_helper/ | Directory exists | Always |
| bats-assert in test_helper/ | Directory exists | Always |
| bats-file in test_helper/ | Directory exists | Always |
