# WalkUpPreamble: Every bash test file MUST begin with the canonical

## Specification Statement

Every bash test file (test_*.sh) MUST begin with the canonical BASH_SOURCE
walk-up preamble immediately after the shebang line and set -euo pipefail.
The preamble MUST locate shared/env.sh via directory traversal and source it
before any test logic executes.

## Rationale

A consistent preamble ensures every test file loads the same environment
regardless of invocation directory.

## Constraints

| Constraint | Value | Condition |
|------------|-------|-----------|
| Preamble is first executable block | After shebang + set | Always |
| Preamble uses BASH_SOURCE[0] | Not PWD or $0 | Always |

## Leaf Value

> 🛑 **Primitive** — terminal specification.

**Value:** `walk-up preamble present and first`

