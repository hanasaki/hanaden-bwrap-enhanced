# SharedEnvContract: shared/env.sh MUST export the project environment

## Specification Statement

The `shared/env.sh` file MUST export at minimum:
- `PROJECT_HOME`: absolute path to project root
- `PROJECT_NAME`: project identifier string
- Any cross-tree indirection variables (e.g., `BWRAP_SH`)

Every variable MUST be exported (not just set) to be available in subshells
and bats test functions.

## Rationale

The env contract is the single source of truth for environment variables.
All scripts source the same file, ensuring consistency.

## Constraints

| Constraint | Value | Condition |
|------------|-------|-----------|
| PROJECT_HOME exported | export PROJECT_HOME=... | Always |
| PROJECT_NAME exported | export PROJECT_NAME=... | Always |
| All variables use export | Not just assignment | Always |
