# TestFileNaming: Bash test files MUST be named test_*.sh and located

## Specification Statement

All bash test files MUST follow the naming convention `test_*.sh` where `*`
is a descriptive snake_case name. Files MUST be located within the `src/test/`
hierarchy, mirroring the SDLC tree structure. This convention enables automated
test discovery via `find src/test -name 'test_*.sh'`.

## Rationale

Consistent naming enables automated test discovery without configuration
files or manifests.

## Constraints

| Constraint | Value | Condition |
|------------|-------|-----------|
| Filename matches test_*.sh | Glob pattern | Always |
| Located in src/test/ hierarchy | Path check | Always |
| Descriptive snake_case name | Convention | Always |
