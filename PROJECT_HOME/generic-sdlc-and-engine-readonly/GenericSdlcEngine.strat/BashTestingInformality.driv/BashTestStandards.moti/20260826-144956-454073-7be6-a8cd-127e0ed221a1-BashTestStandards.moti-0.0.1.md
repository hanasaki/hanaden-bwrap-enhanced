# BashTestStandards: bats-core With Walk-Up Preamble and TAP Pipeline

## Proposed Solution

Standardize all bash testing on three pillars:

1. **bats-core ≥ 1.10** as the mandatory test runner, with bats-support,
bats-assert, and bats-file as standard helper libraries.

2. **Walk-up preamble** in every test file using the canonical BASH_SOURCE
walk-up pattern to locate shared/env.sh and test_helper/.

3. **TAP → JSONL pipeline** to convert bats TAP output into the standardized
JSONL format for machine aggregation.

## Business / Technical Impact

| Impact dimension | Current state | Target state | Delta |
|------------------|---------------|--------------|-------|
| Test runner | Multiple/none | bats-core ≥ 1.10 | Single standard |
| Environment setup | Ad-hoc | Walk-up preamble | Consistent sourcing |
| Output pipeline | None | TAP → JSONL | Machine-parseable |
