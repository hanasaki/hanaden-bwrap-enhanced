# InlinePathProhibition: No Inline Cross-Tree Path Literals

## Specification Statement

Files in src/test/ MUST NOT contain inline string literals that directly
reference paths in src/main/ or other trees. All cross-tree references MUST
go through indirection variables. This includes both `source` statements and
path string constructions.

## Rationale

Inline cross-tree paths create hidden coupling. When the referenced tree
restructures, every inline reference must be found and updated — a process
that is error-prone and often incomplete.

## Constraints

| Constraint | Value | Condition |
|------------|-------|-----------|
| No 'src/main' literal in src/test/ files | grep returns 0 matches | Always |
| No '../main' literal in src/test/ files | grep returns 0 matches | Always |

## Leaf Value

> 🛑 **Primitive** — terminal specification.

**Value:** 0 inline cross-tree path literals
**Source:** Portability requirement

## Measurement Method

```bash
# Scan test tree for cross-tree inline paths
find src/test -name '*.sh' | \
xargs grep -n 'src/main\|\.\..*main' | head -10
# Expected: no output
```
