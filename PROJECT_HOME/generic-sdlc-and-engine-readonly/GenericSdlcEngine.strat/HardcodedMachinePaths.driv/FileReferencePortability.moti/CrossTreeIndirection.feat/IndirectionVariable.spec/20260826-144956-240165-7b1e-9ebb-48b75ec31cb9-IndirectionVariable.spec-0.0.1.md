# IndirectionVariable: Cross-Tree References Via Exported Variables

## Specification Statement

When src/test/ code needs to reference an artifact in src/main/ (e.g., the
bwrap-enhanced.sh script), it MUST reference it via an environment variable
(e.g., `$BWRAP_SH`) that is exported by `shared/env.sh`. The variable MUST
be set during the walk-up sourcing phase.

## Rationale

Indirection variables decouple the test tree from the main tree's internal
layout. If the main tree restructures, only shared/env.sh needs updating.

## Constraints

| Constraint | Value | Condition |
|------------|-------|-----------|
| Cross-tree ref uses $VARIABLE | e.g., $BWRAP_SH | Always |
| Variable exported by shared/env.sh | export BWRAP_SH=... | Always |

## Leaf Value

> 🛑 **Primitive** — terminal specification.

**Value:** `$VARIABLE` indirection pattern
**Source:** Hanaden portability conventions

## Measurement Method

```bash
# Verify indirection variable is set
source shared/env.sh
if [[ -z "$BWRAP_SH" ]]; then
echo "FAIL: BWRAP_SH not set"
exit 1
fi
echo "PASS: BWRAP_SH=$BWRAP_SH"
```
