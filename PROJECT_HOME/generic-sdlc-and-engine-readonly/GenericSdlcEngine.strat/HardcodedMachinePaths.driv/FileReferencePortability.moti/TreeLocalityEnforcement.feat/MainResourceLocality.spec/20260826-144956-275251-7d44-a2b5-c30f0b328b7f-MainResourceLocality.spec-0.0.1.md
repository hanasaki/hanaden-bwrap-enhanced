# MainResourceLocality: Main Resources Live In src/main/ Subtree

## Specification Statement

All main (production) shared resources MUST reside within the `src/main/`
subtree. Production code MUST NOT source or depend on any resource in
`src/test/`. The dependency direction is test → main (via indirection), never
main → test.

## Rationale

Production code that depends on test resources creates a build-time dependency
on the test tree, making it impossible to ship production without tests.

## Constraints

| Constraint | Value | Condition |
|------------|-------|-----------|
| Main resources in src/main/ | Verified by tree scan | Always |
| No main → test dependency | grep returns 0 matches | Always |

## Leaf Value

> 🛑 **Primitive** — terminal specification.

**Value:** Main resources contained in `src/main/`

## Measurement Method

```bash
# Verify no main→test dependency
find src/main -name '*.sh' | xargs grep -n 'src/test' | head -5
# Expected: no output
```
