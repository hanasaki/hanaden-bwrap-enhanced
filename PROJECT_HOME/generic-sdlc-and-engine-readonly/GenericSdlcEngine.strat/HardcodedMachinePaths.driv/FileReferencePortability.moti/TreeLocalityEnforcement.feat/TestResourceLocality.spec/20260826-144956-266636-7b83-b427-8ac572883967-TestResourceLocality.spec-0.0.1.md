# TestResourceLocality: Test Resources Live In src/test/ Subtree

## Specification Statement

All test-specific shared resources — `shared/env.sh`, `test_helper/`, fixture
files — MUST reside within the `src/test/` subtree. Test scripts MUST NOT source
or import shared resources from `src/main/` or any other tree.

## Rationale

Locality ensures that the test tree is self-contained. It can be copied,
moved, or reorganized independently of the main tree.

## Constraints

| Constraint | Value | Condition |
|------------|-------|-----------|
| shared/env.sh in src/test/ | Walk-up finds it in test tree | Always |
| test_helper/ in src/test/ | bats helpers local to test tree | Always |
