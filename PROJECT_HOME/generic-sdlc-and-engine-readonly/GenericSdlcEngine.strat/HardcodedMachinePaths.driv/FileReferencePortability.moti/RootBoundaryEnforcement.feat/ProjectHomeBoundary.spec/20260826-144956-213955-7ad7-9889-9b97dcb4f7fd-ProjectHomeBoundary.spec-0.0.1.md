# ProjectHomeBoundary: Walk-Up Ceiling Is PROJECT_HOME

## Specification Statement

The walk-up discovery loop MUST stop when it reaches PROJECT_HOME or when
it finds the anchor file, whichever comes first. It MUST NOT continue traversing
above PROJECT_HOME into the host filesystem. If the anchor is not found within
the PROJECT_HOME subtree, the script MUST abort.

## Rationale

Traversing above PROJECT_HOME risks finding anchor files from a different
project or exposing the script to host filesystem layout assumptions.

## Constraints

| Constraint | Value | Condition |
|------------|-------|-----------|
| Walk-up stops at PROJECT_HOME | Ceiling enforced | Always |
| No traversal above PROJECT_HOME | Hard boundary | Always |

## Leaf Value

> 🛑 **Primitive** — terminal specification.

**Value:** Walk-up ceiling = `PROJECT_HOME`

## Measurement Method

```bash
# Check walk-up respects boundary
# Run script from outside PROJECT_HOME — should abort
cd /tmp && bash "$PROJECT_HOME/src/test/some_test.sh" 2>&1
# Expected: FATAL error, not success with wrong env
```
