# NoAbsolutePaths: No Hardcoded Absolute Host Paths In Source

## Specification Statement

All source files (`.sh`, `.md`, `.yaml`) in the project MUST NOT contain
hardcoded absolute paths to host-specific locations. The prohibited patterns
include `/homes/`, `/etc/`, `/usr/local/`, and any path that assumes a
specific user account or machine layout.

Exceptions: paths inside sandbox mount specifications (e.g., `--bind /usr /usr`
in bwrap args) are exempt because they describe the *target* filesystem, not
the host.

## Rationale

Any hardcoded absolute path creates a single-machine dependency that breaks
when the project is cloned elsewhere.

## Constraints

| Constraint | Value | Condition |
|------------|-------|-----------|
| No /homes/ in source files | grep returns 0 matches (excl. exceptions) | Always |
| No /etc/ in source files | grep returns 0 matches (excl. bwrap mounts) | Always |
| No /usr/local/ in source files | grep returns 0 matches | Always |
