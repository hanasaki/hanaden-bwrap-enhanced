# WalkUpDiscovery: Canonical BASH_SOURCE Walk-Up Pattern

## Specification Statement

Every bash script MUST begin with the canonical walk-up preamble that uses
`BASH_SOURCE[0]` to determine the script's own directory, then walks up the
directory tree searching for the anchor file (`shared/env.sh`). The walk-up
MUST terminate when the anchor is found or when the filesystem root is reached
(in which case the script MUST abort with a fatal error).

## Rationale

The walk-up pattern is the only portable way to locate project resources
from a script's own perspective. Hardcoded paths break on any directory move.
Relying on `$PWD` breaks when the script is invoked from a different directory.

## Constraints

| Constraint | Value | Condition |
|------------|-------|-----------|
| Walk-up uses BASH_SOURCE[0] | Mandatory in preamble | Always |
| Walks up until anchor found | shared/env.sh | Always |
| Aborts if root reached without anchor | exit 1 with diagnostic | Always |

## Leaf Value

> 🛑 **Primitive** — terminal specification.

**Value:** `BASH_SOURCE[0]` walk-up terminates at anchor or aborts
**Source:** Hanaden bash conventions

## Measurement Method

```bash
# Canonical walk-up preamble
SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
_d="$SCRIPT_DIR"
while [[ "$_d" != "/" ]]; do
[[ -f "$_d/shared/env.sh" ]] && break
_d="$(dirname "$_d")"
done
[[ -f "$_d/shared/env.sh" ]] || { echo "FATAL: shared/env.sh not found" >&2; exit 1; }
source "$_d/shared/env.sh"
```
