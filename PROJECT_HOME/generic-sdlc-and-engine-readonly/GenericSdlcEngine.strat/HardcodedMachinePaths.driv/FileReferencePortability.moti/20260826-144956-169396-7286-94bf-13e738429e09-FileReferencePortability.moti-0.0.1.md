# FileReferencePortability: Walk-Up Discovery and Anchor-Relative File References

## Proposed Solution

All file references in the project MUST be resolved at runtime through
anchor-relative discovery rather than hardcoded absolute paths. The approach
has four components:

1. **Walk-up discovery.** Every script uses `BASH_SOURCE[0]` to determine its
own location, then walks up the directory tree to find the project root
anchor (e.g., `shared/env.sh`).

2. **Root boundary enforcement.** The walk-up MUST stop at PROJECT_HOME and
never traverse above it.

3. **Cross-tree indirection.** When `src/test/` needs to reference `src/main/`,
it uses an indirection variable (e.g., `$BWRAP_SH`) rather than inlining
the path.

4. **Tree locality enforcement.** Resources (shared libs, fixtures) live in
the tree that uses them (`src/test/shared/`, `src/main/shared/`).

## Business / Technical Impact

| Impact dimension | Current state | Target state | Delta |
|------------------|---------------|--------------|-------|
| Path references | Hardcoded absolute | Anchor-relative discovery | Zero absolute paths |
| Walk-up safety | No boundary check | PROJECT_HOME ceiling | Cannot escape project |
| Cross-tree coupling | Direct path references | Indirection variables | Fully decoupled |
