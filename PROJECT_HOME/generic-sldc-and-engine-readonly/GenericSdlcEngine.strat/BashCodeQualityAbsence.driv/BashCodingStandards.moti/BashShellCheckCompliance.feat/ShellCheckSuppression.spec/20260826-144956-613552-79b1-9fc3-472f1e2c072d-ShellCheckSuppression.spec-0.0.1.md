# ShellCheckSuppression: ShellCheck Suppressions Require Justification

## Specification Statement

When a ShellCheck rule must be suppressed (e.g., intentional word splitting),
the suppression MUST use the inline directive format:
```bash
# shellcheck disable=SC2086  # Intentional word splitting for $ARGS expansion
```

The justification comment MUST explain *why* the suppression is safe in this
specific context. Unjustified suppressions (suppression directive without a
comment) are violations.

## Rationale

Unjustified suppressions hide real bugs. The justification requirement
ensures that every suppression is a deliberate decision, not a shortcut
to silence a warning.

## Constraints

| Constraint | Value | Condition |
|------------|-------|-----------|
| Suppression uses # shellcheck disable=SCNNNN | Inline directive format | Always |
| Justification comment follows directive | Same-line comment | Always |
| Unjustified suppression is a violation | Missing comment | Always |

> 🛑 **Primitive** — terminal specification.

## Measurement Method

```bash
# Find unjustified suppressions
grep -rn 'shellcheck disable' --include='*.sh' | \
grep -v '#.*#' | \
head -5
# Lines with disable but no second # comment are violations
```
