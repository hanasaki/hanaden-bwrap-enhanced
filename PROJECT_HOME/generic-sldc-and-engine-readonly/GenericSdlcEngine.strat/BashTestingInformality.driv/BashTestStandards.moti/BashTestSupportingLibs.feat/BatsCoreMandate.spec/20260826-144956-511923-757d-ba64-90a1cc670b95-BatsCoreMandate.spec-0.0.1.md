# BatsCoreMandate: bats-core version 1.10 or higher MUST be available

## Specification Statement

The project MUST use bats-core version 1.10 or higher as the standard bash
test runner. All test_*.sh files MUST be executable via `bats test_file.sh`.
bats-core MUST be installed via mise or available on PATH.

## Rationale

bats-core provides a structured test framework with setup/teardown hooks,
TAP output, and parallel execution — capabilities absent from raw bash scripts.

## Constraints

| Constraint | Value | Condition |
|------------|-------|-----------|
| bats version ≥ 1.10 | bats --version check | Always |
| bats executable on PATH | which bats succeeds | Always |
