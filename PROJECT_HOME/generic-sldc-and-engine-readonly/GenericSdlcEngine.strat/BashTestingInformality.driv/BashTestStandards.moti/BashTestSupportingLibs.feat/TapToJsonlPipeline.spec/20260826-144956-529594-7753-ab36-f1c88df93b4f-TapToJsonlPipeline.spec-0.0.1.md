# TapToJsonlPipeline: bats TAP output MUST be convertible to JSONL via

## Specification Statement

A TAP-to-JSONL conversion pipeline MUST be available to transform bats
TAP output into the standardized JSONL format defined by the TestOutputSchema
feature. The pipeline MUST:
- Accept TAP from stdin
- Emit suite_started, test_case, and suite_finished JSONL records to stdout
- Map TAP 'ok'/'not ok' to PASS/FAIL status

## Rationale

bats produces TAP (Test Anything Protocol) output natively. A pipeline
converts this to the project's JSONL schema for aggregation.

## Constraints

| Constraint | Value | Condition |
|------------|-------|-----------|
| Pipeline accepts TAP stdin | Pipe interface | Always |
| Pipeline emits JSONL stdout | One JSON per line | Always |
| Maps ok→PASS, not ok→FAIL | Status mapping | Always |
