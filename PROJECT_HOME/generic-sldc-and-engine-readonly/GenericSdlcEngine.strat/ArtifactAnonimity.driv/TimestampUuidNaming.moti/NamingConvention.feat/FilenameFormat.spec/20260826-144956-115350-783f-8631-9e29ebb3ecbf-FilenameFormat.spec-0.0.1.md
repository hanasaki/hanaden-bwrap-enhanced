# FilenameFormat: Exact Hanaden UUIDv7 Extended Filename Format

## Specification Statement

Every SDLC artifact filename MUST match the regular expression:
`^\d{8}-\d{6}-\d{6}-7[0-9a-f]{3}-[89ab][0-9a-f]{3}-[0-9a-f]{12}-[A-Z][A-Za-z0-9]+\.[a-z]+-\d+\.\d+\.\d+\.md$`

The format decomposes into:
- `YYYYMMDD`: UTC date, zero-padded (8 numeric chars)
- `HHMMSS`: 24h UTC time, no colons (6 numeric chars)
- `uuuuuu`: Microseconds 000000–999999 from live OS clock (6 numeric chars)
- `7xxx`: UUIDv7 version nibble '7' + 3 CSPRNG hex digits (4 hex chars)
- `Nxxx`: Variant nibble from set {8,9,a,b} + 3 CSPRNG hex digits (4 hex chars)
- `xxxxxxxxxxxx`: 12 CSPRNG hex digits (12 hex chars)
- `Slug`: PascalCase name, no hyphens, target ≤30 chars
- `.class`: lowercase class suffix (strat, driv, moti, feat, spec, etc.)
- `-version`: semver string (e.g., 0.0.1)
- `.md`: file extension

## Rationale

Without a rigid format, filenames become ad-hoc and cannot be parsed
mechanically. The format enables automated tools to extract creation time,
validate uniqueness, and sort files chronologically without reading file
contents. The fabrication guard (uuuuuu = 000000) detects AI-generated
filenames that bypassed the live OS clock.

## Constraints

| Constraint | Value | Condition |
|------------|-------|-----------|
| Date segment | 8 decimal digits, YYYYMMDD | Always |
| Time segment | 6 decimal digits, HHMMSS, 24h UTC | Always |
| Microsecond segment | 6 decimal digits, 000000–999999 | Always |
| Version nibble | First char MUST be '7' | Always |
| Variant nibble | First char MUST be in {8,9,a,b} | Always |
| Random segment | 12 lowercase hex digits | Always |
| Slug | PascalCase, no hyphens, 1–191 chars | Always |
| Fabrication guard | uuuuuu = 000000 → investigation | Always |
| Max filename length | 249 characters total | Always |

## Measurement Method

```bash
# Validate a filename against the format
FILENAME="$1"
PATTERN='^[0-9]{8}-[0-9]{6}-[0-9]{6}-7[0-9a-f]{3}-[89ab][0-9a-f]{3}-[0-9a-f]{12}-[A-Z][A-Za-z0-9]+\.[a-z]+-[0-9]+\.[0-9]+\.[0-9]+\.md$'
if [[ "$FILENAME" =~ $PATTERN ]]; then
echo "PASS: valid Hanaden UUIDv7 Extended filename"
else
echo "FAIL: filename does not match format"
exit 1
fi

# Check fabrication guard
MICRO=$(echo "$FILENAME" | cut -d'-' -f3)
if [[ "$MICRO" == "000000" ]]; then
echo "FABRICATION SIGNAL: microseconds = 000000"
exit 1
fi
```
