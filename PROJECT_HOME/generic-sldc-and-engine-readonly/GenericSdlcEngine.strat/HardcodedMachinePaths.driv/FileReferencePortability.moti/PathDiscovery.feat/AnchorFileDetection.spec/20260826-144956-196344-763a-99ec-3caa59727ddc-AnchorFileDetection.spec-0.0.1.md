# AnchorFileDetection: Walk-Up Anchor Is shared/env.sh With Found-Or-Abort

## Specification Statement

The walk-up pattern MUST search for `shared/env.sh` as the anchor file.
When found, it MUST be sourced to load environment variables. If the walk-up
reaches `/` without finding the anchor, the script MUST print a diagnostic
message to stderr and exit with code 1.

## Rationale

A consistent anchor file across all scripts ensures that every script
loads the same environment contract. The found-or-abort pattern prevents
scripts from silently continuing with undefined variables.

## Constraints

| Constraint | Value | Condition |
|------------|-------|-----------|
| Anchor file is shared/env.sh | Exact filename | Always |
| Anchor sourced on discovery | source "$_d/shared/env.sh" | Always |
| Abort on missing anchor | exit 1 with stderr message | Always |

## Leaf Value

> 🛑 **Primitive** — terminal specification.

**Value:** `shared/env.sh` found-or-abort

```bash
# Test anchor detection

else
echo "FAIL: anchor missing"
exit 1
fi
```
