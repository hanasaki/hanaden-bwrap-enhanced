# CliDefaults: Post-Parse Defaults and HOST_REAL_HOME_DIR Construction

## Specification Statement

After the CLI parse loop completes, the following MUST occur in order:

1. **Default application** (L788-L791):
   If `HOST_REAL_HOME_PARENT` is empty (not set by `--host-real-home-parent`),
   it MUST be set to `HOST_REAL_ROOT_DIR`.

2. **HOME_DIR construction** (L793):
   `HOST_REAL_HOME_DIR` MUST be set to `$HOST_REAL_HOME_PARENT/$VIRTUAL_USER_NAME`.

**Compile-time defaults** (L708-L718, initialized before parsing):
- `VIRTUAL_USER_NAME` = `"sandbox-user"`
- `HOST_REAL_ROOT_DIR` = `"$HOME/virtual-roots"`
- `HOST_REAL_HOME_PARENT` = `"$HOME/virtual-roots/home"`

## Rationale

The default fallback `HOST_REAL_HOME_PARENT = HOST_REAL_ROOT_DIR` handles the
common pattern where a caller passes `--host-real-root /` and expects the home
directory to be resolved relative to that root (i.e., `/sandbox-user`). It also
handles the legacy use case of `virtual-roots/` containing both the root and home.

`HOST_REAL_HOME_DIR` is a derived variable — always constructed as a join of the
parent and the virtual user name. This prevents callers from accidentally passing
an inconsistent home path that doesn't match `VIRTUAL_USER_NAME`. The join happens
post-parse so that both the parent and the name have been fully resolved with any
tilde expansion applied by the parser.

## Constraints

| Constraint | Value | Condition |
|------------|-------|-----------|
| VIRTUAL_USER_NAME default | "sandbox-user" | If not set by --virtual-user-name |
| HOST_REAL_ROOT_DIR default | "$HOME/virtual-roots" | If not set by --host-real-root |
| HOST_REAL_HOME_PARENT default | "$HOME/virtual-roots/home" | If not set by --host-real-home-parent |
| HOST_REAL_HOME_PARENT fallback | HOST_REAL_ROOT_DIR | If empty after parsing |
| HOST_REAL_HOME_DIR | HOST_REAL_HOME_PARENT/VIRTUAL_USER_NAME | Always, after defaults applied |

## Measurement Method

```bash
# Default VIRTUAL_USER_NAME:
./bwrap-enhanced.sh --host-real-root / -- bash -c 'echo $USER'
# Expected: "sandbox-user"

# Default HOST_REAL_HOME_DIR with all defaults:
# (requires ~/virtual-roots/home/sandbox-user to exist)
./bwrap-enhanced.sh -- bash -c 'echo $HOME'
# Expected: /home/sandbox-user

# --host-real-root implies HOME_PARENT fallback:
# (requires /sandbox-user dir to exist)
./bwrap-enhanced.sh --host-real-root / --virtual-user-name agent \
  -- bash -c 'echo $HOME'
# Expected: /home/agent (HOST_REAL_HOME_DIR = //agent)

# Custom HOME_PARENT:
./bwrap-enhanced.sh --host-real-root / \
  --host-real-home-parent /tmp/homes \
  --virtual-user-name myuser -- bash -c 'echo $HOME'
# Expected: /home/myuser (HOST_REAL_HOME_DIR = /tmp/homes/myuser)
```
