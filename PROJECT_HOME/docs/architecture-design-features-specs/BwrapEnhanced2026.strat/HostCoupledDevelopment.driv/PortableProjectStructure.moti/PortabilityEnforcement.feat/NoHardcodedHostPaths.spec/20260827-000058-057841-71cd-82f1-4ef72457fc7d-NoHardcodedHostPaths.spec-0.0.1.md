# NoHardcodedHostPaths: No Hardcoded Absolute Host Paths

## Specification Statement

All source files in the project (any language: `.sh`, `.py`, `.go`, `.rs`, `.md`)
MUST NOT contain hardcoded absolute paths to host-specific locations. Prohibited
patterns include `/homes/`, user-specific account paths (e.g., `Bloom-Frederick`,
`home-remote`), and NFS mount paths.

## Exceptions

- Paths inside sandbox mount specifications (e.g., `--bind /usr /usr`) -- these
  describe the target filesystem, not the host
- Test assertion patterns that check prohibited strings do NOT appear in output
  (negative assertions within grep patterns)
- Security bulletins (`.secbul`) -- historical records of incidents
- Analysis and brainstorming documents

## Rationale

Any hardcoded absolute path creates a single-machine dependency that breaks when
the project is cloned, moved, or tested on any other system.

## Constraints

| ID | Constraint | Condition |
|----|-----------|-----------|
| NHP-C1 | `grep -rn` for `/homes/` in src/ returns 0 matches (excl. exceptions) | Always |
| NHP-C2 | `grep -rn` for known user paths (`Bloom-Frederick`, `home-remote`) returns 0 matches | Always |
| NHP-C3 | Newly added files MUST NOT introduce hardcoded host paths | On every commit |
