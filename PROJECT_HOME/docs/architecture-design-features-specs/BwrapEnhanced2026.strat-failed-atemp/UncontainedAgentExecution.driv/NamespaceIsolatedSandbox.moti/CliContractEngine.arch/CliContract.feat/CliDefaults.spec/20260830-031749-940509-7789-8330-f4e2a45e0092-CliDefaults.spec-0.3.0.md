# CliDefaults: All Flags Default Safe

## Specification Statement

When bwrap-enhanced.sh is invoked with `--dry-run -- CMD` (no passthrough
flags), the resolved configuration MUST show all passthroughs as disabled/off.

## Default Values

| Variable | Default | Type |
|----------|---------|------|
| NET_PASSTHROUGH | false | boolean |
| ENV_PASSTHROUGH | false | boolean |
| X11_PASSTHROUGH | false | boolean |
| WAYLAND_PASSTHROUGH | false | boolean |
| AUDIO_PASSTHROUGH | false | boolean |
| A11Y_PASSTHROUGH | false | boolean |
| DBUS_PASSTHROUGH | false | boolean |
| GNOME_PASSTHROUGH | false | boolean |
| KDE_PASSTHROUGH | false | boolean |
| MISE_PASSTHROUGH | off | graded |
| LOCAL_BIN_PASSTHROUGH | off | graded |
| DRY_RUN | false | boolean |
| VALIDATE_ONLY | false | boolean |
| VIRTUAL_USER_NAME | sandbox_user | string |
