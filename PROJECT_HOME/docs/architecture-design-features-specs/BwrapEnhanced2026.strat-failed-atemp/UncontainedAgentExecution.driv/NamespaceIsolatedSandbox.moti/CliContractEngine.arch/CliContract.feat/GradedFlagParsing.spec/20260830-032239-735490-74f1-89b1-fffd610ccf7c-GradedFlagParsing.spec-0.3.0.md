# GradedFlagParsing: Graded Flag Acceptance (off/ro/rw)

## Specification Statement

Graded passthrough flags (--mise-passthrough, --local-bin-passthrough) support:
1. `--flag` (bare): toggle off->ro (default)
2. `--flag ro`: explicit ro
3. `--flag rw`: explicit rw
4. `--flag off`: explicit off
