# MissingSeparator: CMD Without -- -> ERROR exit 1

## Specification Statement

If a token NOT starting with `-` appears before any `--` separator:
1. Emit `[ERROR] Missing -- separator before CMD: <token>` to stderr
2. Emit `[HINT]  Add -- before your command` to stderr
3. Exit with code 1
