# BoolFlagParsing: Boolean Flag Acceptance

## Specification Statement

Boolean passthrough flags (--net-passthrough, --env-passthrough, etc.)
support three forms:
1. `--flag` (bare): toggles to true
2. `--flag true` / `--flag false`: explicit value
3. Invalid qualifier (e.g. `--flag ro`) rejects with ERROR exit 1
