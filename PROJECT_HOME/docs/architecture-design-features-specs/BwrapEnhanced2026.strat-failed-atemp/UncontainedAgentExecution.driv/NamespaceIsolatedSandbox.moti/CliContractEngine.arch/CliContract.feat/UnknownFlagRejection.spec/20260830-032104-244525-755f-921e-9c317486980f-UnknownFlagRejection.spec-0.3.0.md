# UnknownFlagRejection: Unknown Flags -> ERROR exit 1

## Specification Statement

If a token starting with `-` is encountered in the argument list and does not
match any known flag, the parser MUST:
1. Emit `[ERROR] Unknown flag: <flag>` to stderr
2. Emit `[HINT]  Run with --help to see valid flags` to stderr
3. Exit with code 1
