# EmptyCommandFatal: No CMD After -- -> ERROR exit 1

## Specification Statement

If TARGET_CMD is empty after parse (-- provided but nothing after it):
1. Emit `[ERROR] No CMD provided` to stderr
2. Print usage
3. Exit with code 1 (ERROR, not FATAL)
