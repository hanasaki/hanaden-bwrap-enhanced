## Runtime Flow: bwrap-enhanced.sh Execution Path

> Shows how data flows from operator CLI input through to the running sandbox.

```mermaid
sequenceDiagram
    autonumber
    participant OP as Operator / Orchestrator
    participant CLI as "CLI Parser (L620-L695)"
    participant ID as "Identity Builder (L200-L226)"
    participant EXEC as "exec_sandbox() (L171-L580)"
    participant BWRAP as "bwrap process (kernel)"
    participant INNER as "Inner bash (PID 1 in NS)"
    participant CMD as TARGET_CMD

    OP->>CLI: bwrap-enhanced.sh flags -- CMD args
    CLI->>CLI: Parse flags and validate inputs
    CLI->>CLI: FATAL if any required input missing
    CLI->>ID: Trigger identity construction
    ID->>ID: Build fake_passwd from system UIDs + VUSER
    ID->>ID: Build fake_group from system GIDs + VUSER
    ID->>ID: Build fake_profile with minimal PATH
    ID->>EXEC: Call exec_sandbox()
    EXEC->>EXEC: Build bwrap_args array 12-step VFS
    EXEC->>EXEC: Append --setenv for HOME USER PATH XDG
    EXEC->>EXEC: Append --ro-bind-data FD 9,10,11 for identity files
    EXEC->>EXEC: Append BWRAP_PASSTHROUGH_ARGS last-wins
    EXEC->>EXEC: Build inner bash payload with orphan hold loop
    EXEC->>BWRAP: exec bwrap with 80+ args and FD herestrings
    Note over BWRAP: Shell replaced via exec - no child PID
    BWRAP->>INNER: Launch inner bash as PID 1 in namespace
    INNER->>INNER: Install CHLD trap for zombie reaping
    INNER->>CMD: Run target command in foreground
    CMD-->>INNER: exits with code N
    INNER->>INNER: _CMD_EXIT=N then poll children until empty
    INNER->>BWRAP: exit with CMD exit code
    BWRAP-->>OP: exit code N propagated to caller
```
