# GuiPassthrough: Optional GUI Capability via Explicit Flags

## Rationale

AI agents running browser automation (Playwright, Puppeteer, Selenium) or GUI inspection
tools require display server access. By making all GUI capabilities opt-in flags, the
default sandbox has zero GUI surface area. Callers who need GUI explicitly enable what
they need.
