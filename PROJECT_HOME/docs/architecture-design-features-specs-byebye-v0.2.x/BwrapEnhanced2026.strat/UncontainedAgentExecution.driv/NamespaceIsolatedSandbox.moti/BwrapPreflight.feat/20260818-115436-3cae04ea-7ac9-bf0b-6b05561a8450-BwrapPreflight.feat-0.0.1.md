# BwrapPreflight: Host Environment Preflight Gate

## Specification Statement

Before any bwrap-enhanced.sh behavioral tests run, the host environment MUST be
verified as capable of running bwrap sandboxes. This feature is a GATE: failure
of BwrapMinimalSmoke blocks all Phase 1-3 tests.

## Rationale

bwrap-enhanced.sh depends on:
1. bwrap binary present and executable
2. Kernel support for unprivileged user namespaces
3. newuidmap/newgidmap for UID mapping (required for --unshare-user)
4. A minimal sandbox launch succeeding end-to-end

These are host environment preconditions, not bwrap-enhanced.sh behaviors.
Testing them separately makes Phase 1 failures unambiguous: if the sandbox
doesn't work, the problem is the host, not the spec implementation.

## Specs Under This Feature

| Spec | Gate? | Soft-fail? |
|------|-------|-----------|
| BwrapBinaryPresent | Yes | No — FATAL if absent |
| UserNamespaceEnabled | Yes | No — FATAL if absent |
| NewuidmapPresent | No | Yes — DEGRADED if absent |
| BwrapMinimalSmoke | Yes | No — BLOCKS all Phase 1-3 |
