# VfsIsolation: 12-Step Mount Sequence Provides Isolated Virtual Filesystem

## Rationale

A bare `chroot` leaves the host filesystem fully writable. Linux namespaces with bwrap
allow a precise, ordered sequence of mounts that builds a clean VFS: start with a
read-write host root bind, overlay ephemeral tmpfs on volatile paths, shadow unmanaged
host paths, lock everything read-only, then punch one authorized RW hole for egress.
