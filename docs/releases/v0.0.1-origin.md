# v0.0.1 -- Origin

## Why This Version Exists

Greenfield. This is the initial commit of the hanaden-bwrap-enhanced project --
a sandbox manager built on Bubblewrap (bwrap) for secure, reproducible,
user-namespace-isolated Linux desktop environments.

## Author

Frederick Bloom <devlabs@hanaden.com>

## Starting Point

No prior version. Clean start.

## What Was Built

- bwrap-enhanced.sh: 555 LOC shell script for sandbox provisioning
- SDLC hierarchy skeleton: structured project directory following the
  Hanaden SDLC specification model
- Governance foundation: README, LICENSE, CONSTITUTION (initial drafts)
- 1 test file (placeholder)
- 149 total files

## Motivation

Create a deterministic, auditable, air-gapped sandbox provisioning tool
that wraps Bubblewrap with opinionated defaults for desktop Linux use --
covering bind mounts, environment sanitization, GUI passthrough, and
namespace isolation.
