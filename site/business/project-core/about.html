About V-Universe

Origin

V-Universe emerged from a practical need: as autonomous AI coding agents became central to workflows, the lack of robust, rootless containment was an unacceptable security gap.

Existing solutions — Docker, VMs, chroot — require root access, heavyweight infrastructure, or trust-based isolation. V-Universe solves this with Linux user namespaces: kernel-enforced isolation without elevated privileges.

Mission

Build the simplest possible containment boundary that provides the strongest possible isolation — using only unprivileged Linux kernel primitives.

Guiding Principles

Security by Invisibility

Don't deny access. Remove visibility. No "permission denied" — just absence.

Zero Side Effects

No temp files, no PID files, no state dirs. Clean in, clean out.

Fail Fast, Never Degrade

If a constraint can't be satisfied, abort. Security failures are always loud.

TDD from Day One

Every invariant encoded as executable spec. Tests verify behavior, not code.
