Test Harness

A purpose-built test harness orchestrates the entire test suite with:

  • Parallel execution: Tests run concurrently for fast feedback
  • Deterministic ordering: Reproducible results regardless of execution environment
  • HTML reporting: Rich, browsable test reports with pass/fail/skip breakdowns
  • Category organization: Tests grouped by feature area — namespace, mount, identity, CLI, error handling
  • Regression detection: Automatic comparison against previous runs

Anti-Completion Theater

Tests are only valuable if they're honest. Every test must pass three integrity checks:

Sabotage Test

If you removed the requirement, would the test still pass? If yes — the test is fake.

Mutation Test

If you introduced a deliberate bug, would the test catch it? If no — the test is fake.

Stranger Test

Could someone who didn't write the spec produce the same test? If no — it tests words, not behavior.

What This Means for You

Every release is verified. You're not deploying hope — you're deploying software that has been systematically proven to do what it claims. The test harness is the proof.
