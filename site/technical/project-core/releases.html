v0.4.0-baseline-mvp In Progress

2026-09-01 · Test-Proven Sandbox

Comprehensive automated verification, hardened filesystem checks, unified reporting. The sandbox proves itself through 875 tests.

Added

Test harness: 875 @test declarations across 53 .bats files. JSONL event pipeline with JUnit/JaCoCo/HTML reporting.

Added

Merged HTML dashboard: tab/sidebar navigation, coverage fallback, high-contrast theme for test results.

Added

SDLC Engine Specification v0.0.2 imported — generic deterministic orchestrator with 6 mermaid diagrams.

Changed

bwrap-enhanced.sh: fsck hardening with logging at caller:line granularity.

Changed

Compliance audit: embedded JSON schemas, tooling banner across all harness output.

Fixed

Deleted 43 fake/redundant test specs. Fixed 83 tests to use start subcommand correctly.

Fixed

VirtualRootBind and ZeroSideEffects tests — corrected subcommand usage and skeleton output matching.

2026-08-21 · Security Doctrine

The Immutable Principle crystallizes into formal governance. Enterprise licensing framework established.

Added

v0.1.0

2026-08-18 · GUI Sandbox

The sandbox gains graphical application isolation, selective passthrough, and toolchain integration.

Added

--enable-x11: Read-only bind of XAUTHORITY into sandbox — GUI applications can now display.

Added

--enable-wayland, --enable-audio: selective socket passthrough replacing blanket /run/user bind.

Added

--mise-enable: mise shim passthrough for toolchain access inside the sandbox.

Added

SDLC hierarchy templates: GoalStrategy, DriverMotivation, Feature, Architecture, Specification — all with TDD state tracking.

Added

SDLC Engine Specification v0.0.1 imported — event-sourced state machine with guards, breakers, parallel execution.

Fixed

X11 authentication — sandbox GUI apps now authenticate correctly via read-only XAUTHORITY bind.
