Engine Architecture

Inside the SDLC Engine

The technical architecture: event store, state machine, transition evaluator, and orchestration layer.

Engine Core

The engine is an event-sourced state machine with three primary components:

Event Store

Append-only, immutable log. Partitioned by work-item-id. Every state change is an event. Total ordering within partition.

State Machine

Materialized from event log. Replayable from any checkpoint. Current state is always a pure function of the event history.

Transition Evaluator

Pure function: (state, event) → state'. Deterministic. Same input always produces same output. No side effects.

Star Topology

The orchestration layer uses a star topology for parallel work execution:

Event BusCommunicationStructured events between hub and agents. Typed, versioned, ordered.

Guard System Architecture

Guards are first-class components registered on every node in the artifact hierarchy:

  • Registration: Each node declares 1..N guards at creation time
  • Trigger: Guards fire on every state entry — not just on transitions, but on every observation
  • Actions: Guards can PASS (allow), BLOCK (reject transition), or REDIRECT (force alternative path)
  • Escalation: Blocked transitions generate events that propagate up the hierarchy
  • Emergency: When guard density exceeds thresholds, emergency breakers trip and force system reset
