Technical Drivers

Engineering Constraints That Shape the Engine

The technical requirements and design forces driving the SDLC engine's architecture.

Driver: Event Sourcing

The engine must be fully auditable, replayable, and recoverable. This demands event sourcing:

  • Append-only log: Every state change is an immutable event. Nothing is overwritten or deleted.
  • Replayability: The current state can be reconstructed from any checkpoint by replaying events.
  • Total ordering: Events are ordered per work-item-id. Concurrent work items have independent event streams.
  • Audit trail: Complete history of what happened, when, why, and what triggered it.

Driver: Deterministic Transitions

The state machine must be pure — same input events produce same output states. This enables:

Testing

State transitions can be unit-tested in isolation. Given event X in state S, the output state is always S'.

Recovery

Crash recovery replays the event log. No special recovery procedures. The log IS the recovery mechanism.

Driver: Parallel Execution

Development work is inherently parallelizable. The engine must support concurrent execution without sacrificing correctness:

  • Star topology: Central hub coordinates, independent agents execute. No peer-to-peer complexity.
  • WIP limits: Kanban-style work-in-progress limits prevent overloading.
  • Optimistic concurrency: Agents work independently; conflicts detected and resolved at commit time.
  • DAG dependencies: Tasks declare dependencies; the engine auto-schedules based on the dependency graph.

Driver: Anti-Fixation

Software projects tend toward fixation — repeating patterns even when they're not working. The engine must actively combat this:

  • Inline guards: Every node has 1..N guards that fire on state entry. Guards can BLOCK or REDIRECT transitions.
  • Multi-layer enforcement: Guards at strategy, driver, motivator, feature, spec, and test levels.
  • Emergency breakers: When guards fail and death spirals emerge, circuit breakers force a system reset.
  • Lessons learned: After breaker trips, guards are re-armed with stronger rules derived from the failure.
