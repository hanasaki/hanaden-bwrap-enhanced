Spec Versions

Version history of the Generic SDLC Deterministic Orchestrator Workflow Engine Specification.

v0.0.6 Draft

2,816 lines 35 sections 57 diagrams

OTel-style decomposition with API-contract-first trait crates. Self-documenting repos with STRAT/DRIV/MOTI/FEAT/SPEC document hierarchy. System-of-systems architecture.

Key Changes from v0.0.5.1

  • OTel-style observability decomposition
  • API-contract-first trait crate design
  • Expanded from 15 to 35 sections

v0.0.5.1 ⚠ Experimental

2,525 lines 15 sections 45 diagrams

System-of-systems restructure of v0.0.5: 8 bounded subsystems with clear API boundaries, decomposed machine.json catalog, dedicated TDD and Kanban subsystems.

Key Changes from v0.0.5

  • Restored TDD + RGB feedback clarity (corrupted in v0.0.5)
  • 8 bounded subsystems with clear API contracts
  • Reduced from 3,785 to 2,525 lines (33% leaner)
  • Decomposed machine.json into subsystem catalogs

v0.0.5 ⚠ TDD Corrupted

3,785 lines 25 sections 89 diagrams

Integrated rewrite: one layer taxonomy, one kanban, one merge lifecycle, one exclusive-ownership model, complete event catalog, TDD gate, nested parallel execution.

Key Changes from v0.0.4

  • Parallel execution additions expanded spec significantly
  • 89 mermaid diagrams (peak complexity)
  • ⚠ TDD RED/GREEN cycle corrupted by parallel additions

v0.0.4 ⚠ Experimental

2,328 lines 20 sections 63 diagrams

Integrated rewrite: unified layer taxonomy, kanban lifecycle, exclusive-ownership model, complete event catalog, TDD gate, nested parallel execution.

Key Changes from v0.0.3

  • Expanded from 2,062 to 2,328 lines
  • Added 4 additional diagrams (59 → 63)
  • Refined kanban and merge lifecycle integration

v0.0.3 ⚠ Experimental

2,062 lines 20 sections 59 diagrams

Integrated rewrite: one layer taxonomy, one kanban, one merge lifecycle, one exclusive-ownership model, complete event catalog, TDD gate, nested parallel execution.

Key Changes from v0.0.2

  • Major expansion from 1,017 to 2,062 lines (2× growth)
  • Added 8 new sections (12 → 20)
  • Diagrams increased from 38 to 59
  • Introduced kanban lifecycle and exclusive-ownership model

v0.0.2 ✅ Baseline

1,017 lines 12 sections 38 diagrams

Authoritative baseline specification. Defines a fully implementable software engine for managing the complete software development lifecycle as an event-sourced, deterministic state machine with guards, breakers, and parallel execution.

Key Sections

  • §2 Artifact Hierarchy with RGB feedback paths
  • §3 Anti-Fixation Guards
  • §4 Emergency Breakers
  • §5 Engine Core state machine
  • §6 Star Topology for parallel execution
  • §7 Harvesting and knowledge extraction

Changes from v0.0.1

  • Added Kanban integration and merge-point semantics
  • TDD RED/GREEN/BLUE cycle corrections
  • Expanded from 915 to 1,017 lines

v0.0.1 Superseded

915 lines 12 sections 38 diagrams

Original engine specification. Defines a fully implementable software engine for managing the complete software development lifecycle as an event-sourced, deterministic state machine with guards, breakers, and parallel execution.

Foundation

  • Event-sourced state machine architecture
  • Anti-fixation guards and emergency breakers
  • Star topology for parallel execution
  • Harvesting and knowledge extraction
  • RGB feedback paths (RED/GREEN/BLUE)
