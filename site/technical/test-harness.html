Test Harness

The Pipeline

A complete test execution, normalization, and reporting pipeline. From .bats files to JUnit XML, JSONL event streams, JaCoCo coverage, and a self-contained HTML SPA report.

Pipeline Architecture

Test Execution Pipeline
                                ┌→ JUnit XML    (CI: Jenkins/GitLab)
bats ──→ JUnit XML ──→ JSONL ──┼→ JaCoCo XML   (CI: coverage gates)
                                └→ HTML SPA     (humans: file:// open, git hosting)
StageInputOutputTool
Execute .bats files JUnit XML bats --report-formatter junit --timing
Normalize JUnit XML streaming.jsonl bats-junit-to-jsonl.sh
Report: JUnit streaming.jsonl junit.xml jsonl-to-junit-xml.py
Report: JaCoCo streaming.jsonl jacoco.xml jsonl-to-jacoco-xml.py
Report: HTML streaming.jsonl × N index.html + report.tar.gz merged_html_report.py

Test Suite Layout

Directory Convention
PROJECT_HOME/src/test/hanaden-bwrap-enhanced/suites/
  <FEAT>.feat/
    <SPEC>.spec/
      test_<name>.bats

Example:
  suites/
    BwrapPreflight.feat/
      BwrapBinaryPresent.spec/
        test_bwrap_binary_present.bats    → PF-BIN-001, PF-BIN-002, PF-BIN-004
      BwrapMinimalSmoke.spec/
        test_bwrap_minimal_smoke.bats     → PF-SMOKE-001 … PF-SMOKE-005
    AudioPassthrough.feat/
      PipewireSocketBind.spec/
        test_pipewire_socket_bind.bats    → AUDIO-PW-001

JSONL Event Schema

All test events are normalized into a JSONL stream conforming to the test-event.schema.json schema. Three event types:

suite_started 
{
  "type": "suite_started",
  "trace_id": "460c378c…",
  "suite_name": "…/test_*.bats",
  "test_count": 3,
  "timestamp_unix_ms": 1788259997584
}
test_case 
{
  "type": "test_case",
  "vector_id": "PF-BIN-001",
  "description": "bwrap present on PATH",
  "feat": "BwrapPreflight",
  "spec": "BwrapBinaryPresent",
  "status": "PASS",
  "duration_ms": 16,
  "span_id": "054aaf30…"
}
suite_finished 
{
  "type": "suite_finished",
  "tests_run": 3,
  "tests_passed": 3,
  "tests_failed": 0,
  "tests_skipped": 0,
  "total_duration_ms": 73
}

HTML SPA Report

The merged_html_report.py generator (3,131 lines) scans run directories, embeds all JSONL data as inline <script> blocks, and produces a single self-contained index.html.

Dashboard View

Aggregate pass/fail/skip metrics, trend charts, timing breakdowns. All data from JSONL.

Failure Analysis

Expandable diagnostic output per failed test. stdout/stderr capture with timestamps.

Coverage Matrix

Per-suite feature coverage breakdown with spec-level traceability.

Report Generator Stack

src/lib/report-generators/
├── merged_html_report.py    (3,131 lines — SPA dashboard)
├── junit_html_report.py     (JUnit XML → HTML)
├── jacoco_html_report.py    (JaCoCo XML → HTML coverage)
├── unified_html_report.py   (Combined view)
└── _html_templates.py       (Shared HTML/CSS/JS templates)
